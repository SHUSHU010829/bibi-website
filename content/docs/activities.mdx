# 互動活動

成員可以自掏腰包當獎金，舉辦活動、預測或問答，讓大家一起同樂。

## 活動

舉辦一個自訂活動，由你提供獎金池，機器人協助報名與發獎。

```
/活動 名稱 獎金 名次數 [描述] [最少人數] [最多人數]
```

| 參數 | 說明 | 必填 | 範圍／預設 |
| --- | --- | --- | --- |
| `名稱` | 活動名稱 | 是 | 最多 80 字 |
| `獎金` | 獎金池總額（鎖定用，確認後才扣款） | 是 | — |
| `名次數` | 有幾個得獎名次 | 是 | 1–5 |
| `描述` | 活動說明 | 否 | 最多 500 字 |
| `最少人數` | 達到此人數才能結算 | 否 | 預設 1 |
| `最多人數` | 達上限後拒絕新報名 | 否 | 不填則無上限 |

<Callout type="info">
  **扣款前先確認**：送出 `/活動` 後不會馬上扣錢，而是先跳出一張只有你看得到的確認卡，列出「將鎖定的金額、名次／人數、目前餘額 → 建立後餘額」以及發獎／退款的防洗錢抽成規則，按「確認建立」才真正扣款鎖定獎金池，按「取消」則不扣款。確認卡有 5 分鐘時效。
</Callout>

<Callout type="warn">
  獎金池於**確認後從錢包扣除並鎖定**。若活動取消退款，剩餘款會收 **30% 手續費**再退回主辦人。
</Callout>

### 發獎防洗錢規則

為防止「開活動 → 全額指定發給小帳」淪為繞過轉帳管制的免費搬幣管道，發獎套用與轉帳同一套護欄：

- **獎金抽成**：每筆發出的獎金課 **10% 防洗錢抽成**，得獎者實拿扣抽成後的淨額；但活動**參賽達 5 人**時整場**免抽成**——真實社群活動不受影響。
- **得獎者年資檢查**：結算前檢查每位得獎者，**加入伺服器未滿 7 天**者無法領獎，需重新指定得獎者。
- **金流納入偵測**：活動獎金金流（主辦 → 得獎者）會併入既有的雙向對敲／圈狀轉帳偵測，異常會被標記審查並扣信用分。

## 募資活動

想辦活動但不想自己出全部獎金？用募資活動讓大家一起出錢出物，募到的錢鎖進**活動募資錢包**，只能在這場活動裡發出去。

```
/募資活動 名稱 名次數 [募資目標] [描述] [募資天數] [保留比例] [最少人數] [最多人數]
```

| 參數 | 說明 | 必填 | 範圍／預設 |
| --- | --- | --- | --- |
| `名稱` | 活動名稱 | 是 | 最多 80 字 |
| `名次數` | 有幾個得獎名次（結算時要選出幾位得獎者） | 是 | 1–5 |
| `募資目標` | 卡片進度條的目標金額；**不填就不設目標**，卡片只顯示「已募得多少」 | 否 | 1,000–3,000,000 |
| `描述` | 活動說明 | 否 | 最多 500 字 |
| `募資天數` | 開放募資幾天 | 否 | 1–14，預設 7 |
| `保留比例` | 你可以留下的募款比例 | 否 | 0–10%，預設 0 |
| `最少人數` | 達到此人數才能結算 | 否 | 預設 1 |
| `最多人數` | 達上限後拒絕新報名 | 否 | 不填則無上限 |

### 流程

1. **申請**：送出 `/募資活動`，申請卡會發到審核頻道，你會收到「已送出，等待審核」的確認。
2. **審核**：管理員按「通過，開始募資」或「駁回」（駁回要填理由）。結果會私訊通知你。
3. **募資**：通過後活動卡片發到活動頻道，任何人都能按：
   - **💰 募資 credits** — 輸入金額，最低 100 credits。
   - **🎁 募資物品** — 從自己的背包／魚袋／菜園／道具欄選一種，填數量（獎池最多 10 種物品）。
   - **📊 募資明細** — 看目前募得多少、誰贊助了什麼。
4. **開始報名**：主辦人按「⚙️ 管理 → 🚀 結束募資，開始報名」，募資錢包當場結算成獎金池，活動卡片換成一般活動的「參與／管理」按鈕。截止時間到了也可以直接開始。
5. **結算**：主辦人依序選出各名次 → 填入獎金 → 逐一指定每種物品發給第幾名 → 送出。

<Callout type="warn">
  **募到的錢只能在活動裡發出去**。結算時獎金總和必須**剛好等於獎金池**，多一元少一元都送不出去；物品獎池也必須每一種都指定給某個名次。主辦人保留的比例（最多 10%）在結算完成時才入帳。
</Callout>

<Callout type="info">
  **活動取消 = 全額原路退還**。主辦人或管理員取消募資活動時，所有 credits 與物品會依贊助紀錄退回每位贊助者，主辦人一分都拿不到（連保留比例也沒有）。
</Callout>

發獎同樣套用上面的[發獎防洗錢規則](#發獎防洗錢規則)：參賽未滿 5 人時每筆獎金抽 10%，得獎者年資未滿 7 天不能領獎。

同一個人同時只能有一個進行中的募資活動（審核中／募資中／報名中都算）。

## 預測

發起一個預測題，大家先下注選邊，主辦者稍後公布正解，猜中者瓜分獎金。

```
/預測 題目 獎金 選項a 選項b [選項c] [選項d] [分鐘]
```

| 參數 | 說明 | 必填 |
| --- | --- | --- |
| `題目` | 預測的問題 | 是 |
| `獎金` | 獎金池總額（立即扣除鎖定） | 是 |
| `選項a` / `選項b` | 至少兩個選項 | 是 |
| `選項c` / `選項d` | 額外選項 | 否 |
| `分鐘` | 開放下注的時間 | 否 |

## 問答

發布一題有獎問答，可選擇平分或搶答模式。

```
/問答 題目 獎金 正確答案 選項a 選項b [選項c] [選項d] [分鐘] [模式]
```

| 參數 | 說明 | 必填 |
| --- | --- | --- |
| `題目` | 問題內容 | 是 |
| `獎金` | 獎金池總額（立即扣除鎖定） | 是 |
| `正確答案` | 哪一個選項是正解 | 是 |
| `選項a` / `選項b` | 至少兩個選項 | 是 |
| `選項c` / `選項d` | 額外選項 | 否 |
| `分鐘` | 作答時間 | 否 |
| `模式` | 獎金分配方式 | 否（預設平分） |

| 模式 | 說明 |
| --- | --- |
| 平分獎金 | 所有答對者平分獎金池 |
| 搶答獨佔 | 第一個答對者獨得全部獎金 |

## 紅包

在頻道發一包逼幣紅包，大家限時搶。屬於群組同樂玩法，無莊家抽水——發多少就完整分給搶到的人。

```
/紅包 金額 包數 [手氣]
```

| 參數 | 說明 | 必填 | 預設 |
| --- | --- | --- | --- |
| `金額` | 紅包總金額（最少 100） | 是 | — |
| `包數` | 拆成幾包（最多 20 包） | 是 | — |
| `手氣` | 分配方式：拚手氣（隨機）或均分 | 否 | 拚手氣 |

- **拚手氣**：每包金額隨機分配，手氣好的搶到大包。
- **均分**：每包金額相同，先搶先得。
- 在頻道按按鈕搶包，每人限搶一包，搶完或時間到（預設 10 分鐘）即結束。
- 時限內**未搶完的包數會自動退回**給發包人。
- 可在**公會大廳**（含其聊天討論串）、**賭場遊戲頻道**與**各自的遊戲房**發紅包。

<Callout type="info">
  紅包沒有莊家抽水，發出去的總額會完整分給搶到的人，未搶完的部分原額退回。
</Callout>
