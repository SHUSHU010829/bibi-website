# 礦車軌道 🛤️

一般的[世界事件](/docs/world-events)是隨機觸發、一兩天內結束的短期目標。**主線活動**不一樣：由管理員手動開啟、跑上一到兩週，達標後解鎖的是**永久的新玩法**，不是限時 buff。

第一個主線活動是 **🛤️ 礦車軌道** —— 全服一起把軌道鋪進魔王居所最底層，打通[深層礦脈](/docs/mining/deep-vein)。

## 跟一般世界事件的差別

| | 🌍 一般世界事件 | 🛤️ 主線活動 |
| --- | --- | --- |
| 怎麼開始 | 挖礦 / 釣魚 / 收成 / 通關時隨機觸發 | 管理員手動開啟 |
| 期間 | 24 小時募集 | 14 天募集 |
| 達標獎勵 | 全服 buff（24–48 小時後失效） | **永久解鎖新功能** |
| 參加門檻 | 無 | 需先打造 🔨 拓荒錘 |
| 每日投入 | 無上限 | 有每人每日上限 |
| 佔用並發 | 是（同時最多 1 個） | **否**，跑主線期間一般事件照常觸發 |

<Callout type="info">
  主線活動**不會**佔掉一般世界事件的並發名額，也不吃 72 小時全域冷卻。所以主線跑兩週的期間，平常的世界事件照樣會隨機開。
</Callout>

## 第一步：打造拓荒錘

沒有拓荒錘就投入不了任何資源。到 `/工坊` →「合成」→「活動」分頁打造：

| 道具 | 材料 | 說明 |
| --- | --- | --- |
| 🔨 拓荒錘 | 鐵礦 ×50、煤炭 ×10 | **非消耗品**，打一把用到底 |

## 目標與每日上限

| 物資 | 全服目標 | 每人每日上限 |
| --- | --- | --- |
| 🔩 鐵礦 | 35,000 | 200 |
| 🪙 逼幣 | 14,000,000 | 100,000 |

用 `/世界事件` 打開面板 → 按「🎁 捐獻物資」→ 選物資 → 選數量。

- **鐵礦**優先扣個人背包，不夠才扣公會倉庫。
- **逼幣**直接從錢包扣（**不會**動到銀行定存，也不會動公會金庫）。
- 數量按鈕會**自動夾在今天剩餘額度內**，不會給你按了會失敗的選項。面板上也會顯示「今日額度 X / Y」。
- 每日額度在**台北時間 00:00** 重置。

<Callout type="warn">
  每日上限是刻意設計的 —— 沒有它，幾個囤了大量鐵礦的老玩家兩天就能把進度條清空，其他人連參與的機會都沒有。目標值是依照開活動當下的**實際全服庫存**訂的（鐵礦取總庫存約 70%、逼幣取總流通量約 8%），讓活動大約撐一到兩週。
</Callout>

## 進度公告

進度每跨過一個里程碑，公告頻道會自動發一則（每個階段只發一次）：

- **25%** / **50%** / **75%** —— 進度播報，附視覺化進度條
- **100%** —— 達標公告，深層礦脈永久開放

`/世界事件` 面板上隨時看得到目前進度：

```
• 🔩 鐵礦　22,000 / 35,000
`████████░░░░ 62%`
• 🪙 逼幣　10,000,000 / 14,000,000
`█████████░░░ 71%`
```

## 貢獻稱號

活動達標時自動結算並發放，稱號**沒有任何數值加成**，純粹是紀念。

| 稱號 | 條件 |
| --- | --- |
| 🔨 拓荒先鋒 | 貢獻度 ≥ 1% |
| ⛏️ 拓荒英雄 | 貢獻度 ≥ 2.5% |
| 👑 礦道守護者 | 貢獻度 ≥ 4% |
| ✨ 深層礦脈開拓者 | 貢獻榜**前 3 名**（限定） |

### 貢獻度怎麼算

鐵礦目標 35,000、逼幣目標 14,000,000，兩者差了 400 倍。如果把投入的**原始數量直接相加**，逼幣會完全主導 —— 專心倒鐵礦的人反而拿不到稱號。

所以貢獻度是**各物資先除以自己的目標，再取平均**：

```
貢獻度 = ( 你的鐵礦 ÷ 35,000  +  你的逼幣 ÷ 14,000,000 ) ÷ 2 × 100%
```

舉例：投入鐵礦 2,800（目標的 8%）+ 逼幣 700,000（目標的 5%），貢獻度 = (8% + 5%) ÷ 2 = **6.5%**，拿到拓荒先鋒、拓荒英雄、礦道守護者三個。

<Callout type="info">
  兩種資源都投入比只押一邊有利。以每日上限推算，全程每天都投滿的玩家大約能累積到 **4–5%**，所以 👑 礦道守護者是留給幾乎天天都參與的人的。
</Callout>

## 達標之後

- [深層礦脈](/docs/mining/deep-vein) `/深挖` **永久開放**（個人還需等級 30）
- 🔮 魔晶礦開始流通，賭石也會有極低機率開出（解鎖前不會）
- 解鎖魔晶裝備四件、魔晶維修工具、魔晶熬煮宴、封魔彈藥
- 公會端解鎖熔爐 Lv.3（產魔晶合金）、精煉站 Lv.4／Lv.5、倉庫擴建 Lv.6／Lv.7

解鎖是**永久旗標**，不會過期，之後加入伺服器的新玩家也同樣適用。
